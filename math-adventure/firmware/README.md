# v0.4.3 四位码配对（当前）

手机配网页面只需扫描选择Wi-Fi并填写密码，无需设备令牌。后端默认`https://ryven.xin/math`。

家长网页使用邮箱验证码登录，每个邮箱是独立用户。在设备管理开启四位码配对，ESP32首页“配对设备”或“小设置 → 开启配对”输入数字码；核对两端显示的设备名称及6位校验号后，在网页确认。配对后自动保存设备凭证，重启无需重新配对。需要服务器先部署本次邮箱登录/配对接口。

配对码3分钟有效，一次绑定；输入四位后点击“确认”提交，支持0开头；“返回”和“删除”独立可点。进入键盘前先校验家庭Wi-Fi及后端健康状态，离线时显示网络检查页。配对请求及凭证写入NVS，联网工作在后台，未确认的提交不改变任务或积分。网页确认后才获得所选正式/试玩角色的数学任务权限。

构建与触摸配置沿用下文，旧手填令牌说明属于历史版本。

# ESP32联网固件 v0.3.1

当前固件已切换为服务端任务与判题，不再运行本地三题试玩。正式/试玩标记由设备令牌在后端绑定的模式决定，不能在板上自行修改正式余额。

## 首次配置

1. 在 https://ryven.xin/math/ 家长页面创建设备。正式模式只使用人工审核发布题目；独立试玩用于测试草稿。保存只显示一次的**设备令牌**，不使用家长令牌。
2. 板子未配置时自动显示配网热点。手机连接屏幕显示的`Math-Setup-xxxx`，密码显示在屏幕上，首次生成后保存，后续重启保持不变。
3. 手机连接后会通过系统的热点登录入口打开配置页；如未自动弹出，手动打开`http://192.168.4.1/`，从扫描列表选择家庭2.4GHz Wi-Fi，输入密码及设备令牌。支持按信号强弱排序、同名网络去重、重新扫描及无密码网络识别，不提供手动输入Wi-Fi名称。后端地址默认`https://ryven.xin/math`，不要额外加`/api`。
4. 保存后回到首页等待联网同步。没有正式已发布题目时显示空任务，先在家长页面审核并安排。
5. 日后可从“小设置”开启热点或重新校准触摸。热点十分钟后关闭，可以再次手动开启。

设备令牌和Wi-Fi密码只在本地配置，不回显已有秘密。配置页面仅允许通过设备热点访问，并校验随机表单令牌。密码/设备令牌留空保留原值，切换开放Wi-Fi需勾选无密码。存在未确认提交时先同步确认，再修改服务器或设备归属。

## 联网行为

- HTTPS使用根证书及NTP校时验证，没有跳过证书校验。当前打包DigiCert根证书，适用于本次核对的ryven.xin证书链。
- 网络运行在独立FreeRTOS任务，主线程处理触摸、配网页面和绘图。单次网络失败不会阻塞触摸等待。
- 答案/提示/跳过请求先以一个完整JSON写入独立NVS，再发送。断网与重启重用原请求ID及负载；只有可解析的服务端确认响应才结算，不进行本地判题或发奖。
- 服务器明确返回401、404、409、422时停止重试该提交，提示重新配置或同步；网络错误与服务端错误保留请求重试。
- 首页定时同步，重新进入地图可手动同步；按服务器日期恢复当天进度。原离线试玩进度不导入正式记录。
- 原题、选项、提示和方法支持16px UTF-8换行及翻页；长选项显示在正文，以编号按钮选择。方法页仍保留完整题目。
- 点击空白处不重绘，按钮反馈仅改边框。状态未改变的自动同步不重绘整页。

# ESP32卡通触摸试玩版 v0.2

这是可独立操作的**本地试玩版**，用于验证中文、卡通画面、触摸与闯关体验。采用TFT_eSPI和16px中文点阵字体，无需PSRAM；正式题库审核、Wi-Fi、服务器判题、家长页面和真实积分尚未接入。试玩始终显示标记，不产生正式学习记录。

已实现首页、三个关卡、答题、提示、鼓励重试、稍后再想、方法回看、休息总结和设置。完成的关卡收集星星，重复回看不会重复累计；跳过不计作答对。试玩进度和触摸校准分别保存到独立的`math-playtest` NVS空间，重启后保留。

## 硬件依据

参考[厂商E32R32P引脚表](https://www.lcdwiki.com/3.2inch_ESP32-32E_Display#ESP32_Pin_Assignment)：ST7789P3屏幕，XPT2046电阻触摸。二者共享SCLK=14、MOSI=13、MISO=12，LCD CS=15、DC=2，触摸CS=33，背光=27；不能套用其他CYD板的独立触摸总线引脚。横屏使用rotation=1，真机颜色、方向和触摸仍需实际检查。

声音与麦克风不在本轮实现范围；GPIO4按厂商说明置高关闭功放。数学固件没有AHT20采集和上传。

## 编译、烧录

```sh
pio run -d math-adventure/firmware
pio run -d math-adventure/firmware -t upload --upload-port /dev/cu.usbserial-1440
pio device monitor --baud 115200 --port /dev/cu.usbserial-1440
```

首次开机依次轻按屏幕上的三个十字，每次停留约0.2秒再松手；最后点第四个十字确认。坐标异常会重新校准，校准成功自动进入首页。使用圆头触控笔或指甲轻点电阻屏，勿用尖锐物。以后可在“小设置 → 校准触摸”重新校准。

## 串口辅助验证

| 输入 | 操作 |
| --- | --- |
| h | 输出帮助 |
| 0 / 1 | 首页 / 地图 |
| a / b / c | 在地图选择第1/2/3关，在答题页选择第1/2/3个答案 |
| n | 开始，或从方法页继续 |
| t / r / s | 提示 / 返回重试 / 稍后再想 |
| C | 重新校准触摸（大写） |
| d | 输出原始触摸坐标与压力 |
| x | 清空试玩进度并回首页（不清校准） |

串口可以在校准等待时输入0或1进入页面，以便无人触摸时验证显示和流程。此方式不等于触摸验收。

### 共享题库与每日5题（2026-11-23）

所有邮箱共享题目、草稿和审核结果；管理员令牌通过POST导入的题也会出现在所有邮箱的题库中。题目不再按邮箱复制，原有题目与历史版本保留。设备、每日计划、作答记录、错误次数、经验和金币仍按邮箱及正式/试玩模式隔离。

每日自动安排5道未做过的基础题，题量不足时安排现有可用题；旧的自动3题计划会补足，手动设置的计划不会被覆盖。地图支持翻页，不再限制只能看到3题。家长也可手选1～5道基础题。

ESP32地图和家长页面提供「随机探索」，只从已发布且未停用的题中随机追加1道，排除当前账号已作答的题（含做错的）以及当天已安排的题；没有新题时直接提示。随机探索为额外任务，不改变基础5题的每日奖励结算，设备重复上传同一抽题请求不会重复分配。设备分批同步5道题，更多探索关卡可翻页获取；已同步关卡继续本地判题并异步上传记录。
