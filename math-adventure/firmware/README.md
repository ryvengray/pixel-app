# ESP32卡通触摸试玩版 v0.2

这是可独立操作的**本地试玩版**，用于验证中文、卡通画面、触摸与闯关体验。采用TFT_eSPI和16px中文点阵字体，无需PSRAM；正式题库审核、Wi-Fi、服务器判题、家长页面和真实积分尚未接入。试玩始终显示标记，不产生正式学习记录。

已实现首页、三个关卡、答题、提示、鼓励重试、稍后再想、方法回看、休息总结和设置。完成的关卡收集星星，重复回看不会重复累计；跳过不计作答对。试玩进度和触摸校准分别保存到独立的`math-playtest` NVS空间，重启后保留。

## 硬件依据

参考[厂商E32R32P引脚表](https://www.lcdwiki.com/3.2inch_ESP32-32E_Display#ESP32_Pin_Assignment)：ST7789P3屏幕，XPT2046电阻触摸。二者共享SCLK=14、MOSI=13、MISO=12，LCD CS=15、DC=2，触摸CS=33，背光=27；不能套用其他CYD板的独立触摸总线引脚。横屏使用rotation=1，真机颜色、方向和触摸仍需实际检查。

声音与麦克风不在本轮实现范围；GPIO4按厂商说明置高关闭功放。数学固件没有AHT20采集和上传。

## 编译、烧录

```sh
pio run -d math-adventure/firmware
pio run -d math-adventure/firmware -t upload --upload-port /dev/cu.usbserial-1440
pio device monitor --baud 115200 --port /dev/cu.usbserial-1440
```

首次开机依次轻按屏幕上的三个十字，每次停留约0.2秒再松手；最后点第四个十字确认。坐标异常会重新校准，校准成功自动进入首页。使用圆头触控笔或指甲轻点电阻屏，勿用尖锐物。以后可在“小设置 → 校准触摸”重新校准。

## 串口辅助验证

| 输入 | 操作 |
| --- | --- |
| h | 输出帮助 |
| 0 / 1 | 首页 / 地图 |
| a / b / c | 在地图选择第1/2/3关，在答题页选择第1/2/3个答案 |
| n | 开始，或从方法页继续 |
| t / r / s | 提示 / 返回重试 / 稍后再想 |
| C | 重新校准触摸（大写） |
| d | 输出原始触摸坐标与压力 |
| x | 清空试玩进度并回首页（不清校准） |

串口可以在校准等待时输入0或1进入页面，以便无人触摸时验证显示和流程。此方式不等于触摸验收。
