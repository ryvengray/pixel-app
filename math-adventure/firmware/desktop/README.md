# 在电脑上运行冒险岛界面

在项目根目录执行（macOS / Linux）：

```bash
python3 math-adventure/firmware/desktop/run.py
```

在浏览器打开 http://127.0.0.1:8790 。终端保持运行，Ctrl+C 退出；端口被占用可使用 `--port 8791`。

需要 Python 3 和 C++17 编译器。macOS 通常已有 Xcode 命令行工具，没有时运行 `xcode-select --install`。首次启动自动下载与固件一致的 ArduinoJson 6.21.5，之后可以断网运行，无需 pip、PlatformIO 或连接板子。下载依赖和本地编译产物保存在已被 Git 忽略的 `.cache` 中。

## 操作

- 用鼠标点击屏幕中的按钮，等同触摸相应坐标。
- 可选择 1×、2×、3×，或显示触摸区域检查点击范围。
- 五道本地题：四道选择题加一道数字填空题。可测试地图翻页、答错、提示、成功、解析、数字键盘、稍后再想。
- 「重置本地试玩」恢复初始数据；重启程序同样重置。
- 设置里的配对、Wi-Fi、随机探索、服务器同步使用本地占位操作，不会向真实服务发请求。

## 与固件的关系

这不是 ESP32 CPU / Wi-Fi / 屏幕控制器的硬件仿真器。电脑编译运行的是共用的真实 C++ 界面代码，绘图命令交给本地浏览器 Canvas 显示。

- `src/screen_ui.h`：共用的页面渲染、文字分页、按钮与页面切换。
- `src/screen_primitives.h`：共用的文字、按钮、角色和星星绘图。
- `desktop/preview.cpp`：电脑显示适配及本地答题逻辑。
- `desktop/run.py`：编译、生成本地样题、提供仅绑定 127.0.0.1 的预览入口。

优化界面时修改前两个共用文件，然后停止并重新运行上述命令，ESP32 下次编译也会使用修改后的代码。固件网络同步、离线队列与积分结算在电脑预览中没有复现，不能用此预览验证这些功能。

中文字体由操作系统近似显示，不是板子的16px点阵字体；颜色、文字最终宽度、触摸手感和刷新速度仍需最后上板确认。

## 数据隔离

不需要邮箱、不需要设备令牌、不连接正式数据库，无法撤销或替换真实设备，也不会改变孩子的题目、任务、答题历史或积分。

## 自动检查

```bash
python3 math-adventure/firmware/desktop/run.py --smoke-test
```

检查真实按钮命中、地图、选择题答错、提示、答对、方法页、数字填空键盘及重置。此命令不会启动 HTTP 服务。
