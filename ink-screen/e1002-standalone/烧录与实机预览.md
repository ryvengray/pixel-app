# E1002 独立版烧录与实机预览

## 当前状态

山水月历已经写进浏览器交互稿。当前目录只有设计和网页，没有 ESP32-S3 固件工程、PlatformIO 配置或可烧录文件，所以暂时不能把这套独立版刷进 E1002。

仓库里的 [现有 E1002 固件](../pixel-display-e1002/README.md) 是连接 Pixel 服务端拉取画面的版本。烧录它会写入那套程序。扫码配网、设备自己计算日历以及左下角扫码上传，需要由独立版固件实现。

## 现在可以在设备上看静态样张

如果 E1002 已经装有 Pixel 服务端版固件，且对应服务支持图片接口，可以提交导出的 800 × 480 日历 PNG，再按绿色刷新键查看。这样可以检查真实墨水屏上的颜色、字号和留白。

1. 将预览 PNG 保存到电脑。确认设备编号和 Pixel 服务地址，令牌使用服务端现有的 `PIXEL_TOKEN`。
2. 在 Mac 的终端运行以下命令。先替换示例地址、设备编号和 PNG 路径，再在提示下输入令牌。

   ```zsh
   pixel_api='http://192.168.1.10:18000'
   pixel_device='desk-01'
   png_file="$HOME/Downloads/e1002-landscape-calendar.png"
   read -rs 'pixel_token?输入 PIXEL_TOKEN：'
   printf '\n'

   curl --fail-with-body --silent --show-error \
     --header @- \
     --header 'Content-Type: image/png' \
     --data-binary "@$png_file" \
     "$pixel_api/v1/devices/$pixel_device/image" <<EOF_HEADERS
   Authorization: Bearer $pixel_token
   EOF_HEADERS
   unset pixel_token
   ```

3. 接口返回 `version` 后，按绿色刷新键获取最新画面，也可以等设备下一次定时唤醒。提交样张会将它设为该设备的最新画面。样张日期固定，左下角是演示二维码，适合检查版式。

## 独立版固件就绪后的烧录流程

等独立版目录提供固件工程和可编译的 `platformio.ini` 后，再按该工程给出的具体路径和环境名操作。

1. 用支持数据传输的 USB-C 线将 E1002 接到 Mac，打开设备电源。若 Mac 没发现串口，检查数据线和电源，再按 Seeed 指南排查驱动。 [Seeed E1002 USB 与 macOS 串口说明](https://wiki.seeedstudio.com/getting_started_with_reterminal_e1002/)
2. 在 PlatformIO 终端运行 `pio device list`，记录插入 E1002 后出现的串口。 [PlatformIO 串口列表](https://docs.platformio.org/en/stable/core/userguide/device/cmd_list.html)
3. 进入独立版固件目录，运行 `pio run -e <独立版环境名>`。编译成功后，执行 `pio run -e <独立版环境名> -t upload --upload-port <设备串口>`，等待写入校验和 `SUCCESS`。命令里的尖括号内容要替换成工程提供的环境名和实际串口。 [PlatformIO 编译与烧录命令](https://docs.platformio.org/en/latest/core/userguide/cmd_run.html)
4. 重启后先确认屏幕显示独立版配网二维码。完成配网后检查月历是否显示当天，并验证长按绿色刷新键开启上传、左下角扫码上传，以及短按切换模式。完整用例见 [实机验收](README.md#实机验收)。

如果设备正在使用 Pixel 服务端版，升级前保留该版本的固件源码、分区配置和本机配置。现有版本的恢复步骤见 [E1002 固件烧录与更新说明](../pixel-display-e1002/固件更新说明.md#8-保留可回退版本)。
