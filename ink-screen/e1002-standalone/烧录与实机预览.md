# E1002 独立版烧录与实机预览

## 当前状态

`firmware/` 已包含可编译的 ESP32-S3 独立版工程和内置手机页面，不再仅是浏览器交互稿。环境名为 `e1002-standalone`，不需要填写 Wi-Fi 配置文件，不需要 Pixel 服务端。

固件已经通过编译和主机自动测试，完整硬件验收项目见 [实机验收](README.md#实机验收待执行)。

## 编译

从 `pixel-app` 仓库根目录运行：

```sh
pio run -d ink-screen/e1002-standalone/firmware -e e1002-standalone
```

如果 `pio` 不在 PATH，本机可使用 `/Users/ryven/.platformio/penv/bin/pio` 替换。首次构建需要下载已固定版本的依赖；后续可使用缓存。

产物在 `ink-screen/e1002-standalone/firmware/.pio/build/e1002-standalone/`：

- `firmware.bin`：应用程序。
- `bootloader.bin`、`partitions.bin`：引导程序和独立版分区表。
- `firmware.elf`：调试用符号。

上传页面自动编译进应用，无需运行 `uploadfs`。本工程使用 8 MB Flash、OPI PSRAM 和 3 MiB 相册分区；没有 OTA 分区。

## 从现有固件切换

独立版的分区表与 Pixel 服务端版不同。升级前保留原工程、分区配置、设备配置及必要的整片 Flash 备份，恢复办法见 [现有固件烧录说明](../pixel-display-e1002/固件更新说明.md#8-保留可回退版本)。仅写入 `firmware.bin` 不足以切换分区表，使用以下 PlatformIO 上传命令。

如果旧数据导致独立版 LittleFS 挂载失败，固件不会自动格式化已有内容。烧录后通过「同时长按前进和后退 → 恢复出厂 → 再按刷新确认」初始化独立版存储；这会清除相册和网络。无需机身复位按钮，也无需盲目擦除整片 Flash。

## 连接、烧录和串口

1. 使用支持数据传输的 USB-C 线连接 E1002，打开设备电源。
2. 查看插入后出现的串口：

   ```sh
   pio device list
   ```

3. 将下例串口替换为实际路径，再上传：

   ```sh
   pio run -d ink-screen/e1002-standalone/firmware \
     -e e1002-standalone -t upload --upload-port /dev/cu.usbserial-实际端口
   ```

4. 等待写入校验和 `SUCCESS`，设备会自动重新启动。若程序已经休眠，可以按任一现有按键唤醒；需要重新供电时使用设备电源开关，无需专用重置键。
5. 可选查看日志（使用板载 USB-UART，GPIO43/44，115200）：

   ```sh
   pio device monitor --port /dev/cu.usbserial-实际端口 --baud 115200
   ```

## 首次使用

1. 屏幕显示设备热点名、固定密码 `12345678`、Wi-Fi 二维码和 `http://192.168.4.1`。
2. 手机扫描左侧 Wi-Fi 二维码加入热点；如未弹出配网页，扫描右侧「配网页二维码」或在浏览器手动打开该地址。若扫码工具显示 `WIFI:T:WPA;…` 文本，改用系统相机或手动连接屏上热点；这段内容是 Wi-Fi 入网信息。
3. 输入家庭 2.4 GHz Wi-Fi；时区默认采用手机当前偏移，提交时同步手机时间。
4. 成功后手机切回家庭网络，扫描月历左下角二维码，选图、调整取景并上传。
5. 设备确认保存后自动进入照片模式，屏幕刷新期间手机显示进度状态。手机页面顶部的「系统设置」可校时、设置时区、切换画面、重配网络及打开设备上的恢复出厂确认页。

以后长按绿色刷新键约 1.5 秒开启上传窗口；短按刷新键切换照片/月历，前后键离线翻页。

## 烧录后仍保留旧画面

电子纸在旧程序、休眠、甚至断电时都会保留原图，仅看到旧画面不能证明新固件已运行。检查上传输出中的工程路径和环境名，必须是本目录的 `e1002-standalone`，而不是 `pixel-display-e1002/firmware` 下的 `e1002`。

串口启动日志应包含 `[e1002-standalone] built ...`、`[standalone] setup complete`，首次刷新会打印 `display start`，完成后打印 `display complete`。冷启动和重新烧录会强制重新绘制；只有深睡恢复才按画面指纹跳过相同内容。日志不会打印热点密码或上传码。

## 双键重置入口

同时长按 **前进（GPIO4）＋后退（GPIO5）约 1.5 秒** 打开设备设置。前后键选择，刷新键短按确认：

- 重配网络：保留照片，重新打开热点配网。
- 恢复出厂：先进入确认画面，再按一次刷新键清除；前后键可取消。
- 返回画面：取消设置；也可再次双键长按退出。

双键释放不会触发单键翻页。没有任何步骤依赖额外的机身重置按钮。

## 自动测试

```sh
python3 ink-screen/e1002-standalone/firmware/tools/check.py
```

测试不会访问或擦写真实设备。实机测试清单见 [README](README.md)。

## USB 导出画面（调试）

需要查看实际渲染结果时，可以通过 USB 导出最近完成的 800 × 480 画面。它是发送给屏幕的像素截图，不是实体屏照片；六色的实物观感以设备为准。此功能不需要开启上传服务。

从仓库根目录运行（Python 环境需要 pyserial，PlatformIO 的 Python 已包含）：

```sh
python3 ink-screen/e1002-standalone/firmware/tools/capture_screen.py \
  --port /dev/cu.usbserial-实际端口 --restart --output /tmp/e1002-screen.bmp
```

`--restart` 通过 USB 重新启动设备，保留配置和相册；截图等待本次全刷完成，并校验完整像素数据。设备已唤醒时可省略该参数以获取当前已完成的画面。
