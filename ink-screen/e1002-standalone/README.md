# E1002 独立版

一台可以送人的桌面月历和相框。ESP32 自己保存配网信息、计算日历、接收图片和管理相册。手机用浏览器操作，无需账号、专用 App 或常驻服务器。

`firmware/` 现在提供可编译的 ESP32-S3 独立版工程，包含配网、月历、上传、相册和休眠。已通过 PlatformIO 编译及主机自动测试；Android/iPhone 配网、实体屏二维码、三键唤醒、RTC 保时和耗电仍需实机验收。烧录方法见 [烧录与实机预览](烧录与实机预览.md)。

[浏览器交互稿](design/index.html) 用于预览设计，不连接设备；真实手机页面位于 `firmware/web/`，随编译嵌入固件。

## 开箱和上传

1. 首次开机或恢复出厂后，设备建立临时热点，固定密码为 `12345678`。扫描屏上左侧 Wi-Fi 二维码加入热点，在配网页输入家里 2.4 GHz Wi-Fi 的网络名和密码。若没有自动弹出页面，扫描右侧「配网页二维码」或打开 `http://192.168.4.1`。左侧二维码使用 `WIFI:T:WPA;…` 格式，作用是加入热点，不是打开网页；若扫码工具只显示文字，可用系统相机扫码或手动连接屏上的热点。手机提示热点无互联网时，选择继续连接。
2. 配网页同时提交手机时间和本地 UTC 偏移。设备保持热点开放并尝试连接家庭网络，最多等待约 20 秒；成功后才保存配置并显示当天月历，失败可在原页面重试。切回家庭 Wi-Fi 后扫描墨水屏左下角二维码，页面顶部可选择「上传图片」或「系统设置」。
3. 后续传图，长按绿色刷新键约 1.5 秒。设备连接已保存的 Wi-Fi，启动 `8080` 端口上传服务，保持当前月份或照片。手机需要连接到允许与设备互通的局域网。
4. 选择照片，在固定 5:3 取景框中调整缩放、水平和垂直位置。手机展示最终 800 × 480 六色效果及待传大小；左下角白色区是设备二维码覆盖范围。确认后发送，原图留在手机。
5. 手机先显示「已保存到相册」，再轮询屏幕刷新状态。彩屏全刷通常需要十几到几十秒，期间仍可接收上传和按键；待显示的多次操作合并到最终页。
6. 上传窗口从服务启动起开放 5 分钟。打开上传首页、有效配网提交、成功上传和长按刷新键会重新计时；状态轮询、静态资源及无效请求不续时。活跃上传不休眠，单次传输限时 120 秒。空闲到期后关闭服务、Wi-Fi 并深睡，屏幕保留原画面。

二维码白底区域位于左下角 `(0, 320)`，大小为 160 × 160。服务关闭时，日历二维码编码离线文字说明：长按绿色键开启服务，联网后重扫即可上传或设置；离线时长按左键和中键进入设备设置。说明直接存放在二维码里，无需联网。上传服务启动后，二维码切换成有效的局域网操作页地址。右上角显示电量百分比和服务图标：绿色实心圆点表示 Web 服务可用，空心圆点表示已关闭。电量根据电池电压估算，刷新画面时采样。开启或关闭服务均会全刷以更新图标；服务到期后先关闭服务和 Wi-Fi，再画出关闭状态，等全刷结束才深睡。IP 变化时同时更新在线二维码。日历模式保留二维码，照片模式平时隐藏，仅在上传服务开启期间显示；关闭时的全刷会恢复二维码下面的照片。若网络隔离无线客户端，需要切换到允许设备互通的网络。

## 按键和重置

设备只使用现有的三个按键，**不需要额外的重置按钮**。

| 按键 | 日历模式 | 图片模式 |
| --- | --- | --- |
| 刷新短按（GPIO3） | 切到上次查看的照片 | 切回月历 |
| 刷新长按约 1.5 秒（GPIO3） | 开启或续期上传，保留当前月 | 开启或续期上传，保留当前照片 |
| 后退（GPIO5） | 上一月 | 上一张 |
| 前进（GPIO4） | 下一月 | 下一张 |
| 同时长按前进＋后退约 1.5 秒 | 进入设备设置 | 进入设备设置 |

设置页用前后键选择，短按刷新键确认：

- **返回画面**：退出设置；也可以再次同时长按前后键退出。
- **重配网络**：清除原 Wi-Fi 配置并重新开热点，保留相册、上传码和显示状态。
- **恢复出厂**：进入清除确认页，再短按刷新键才执行；按前后键取消。清除 Wi-Fi、所有照片、显示状态及上传码，并重新配网。清除过程中断电会在下次启动继续清除。

三键均可唤醒设备。离线翻页和切换模式不打开 Wi-Fi；相册在首尾停止。长按后松手不触发短按，组合键松手不会意外翻页。已保存的 Wi-Fi 连接失败时，屏幕提示使用上述双键入口重配。

## 手机端系统设置

长按绿色刷新键开启服务，重新扫描屏幕上的在线二维码，在手机页面顶部选择「系统设置」：

- 查看电量、相册数量、当前显示模式、Wi-Fi、IP、设备时间和窗口剩余时间。
- 切换到本月月历或最近上传的照片。设备执行后返回结果，屏幕全刷另需十几到几十秒。
- 用手机时间校准 RTC，并保存固定 UTC 偏移；修改时区不需要重新配网。
- 重配 Wi-Fi：点击后会断开当前页面并打开设备热点，照片保留；按屏幕提示重新配网。
- 恢复出厂：手机点击只打开实体屏上的确认画面。等确认画面显示完成，再短按绿色刷新键清除；前后键取消。

打开设置页或提交有效设置会续期 5 分钟；后台设备信息和执行结果轮询不会续期。接口使用与上传相同的设备凭据，未授权、无效参数和重复的并发操作会被拒绝。操作先进入队列，再由设备执行并返回实际结果。

## 实现说明

- **显示**：沿用现有 E1002 工程的 Seeed 六色驱动、SPI 接线和三键映射。设备端绘制横向月历、中文农历、节日和山水；日历保留真实上传二维码，照片仅在上传窗口开启时叠加二维码。屏幕字形使用 U8g2 文泉驿字库。固件版排版由设备端实现，浏览器稿不是截图下发。
- **日历**：周一为首列，补齐跨月日期，支持闰年、跨年和六行月份，蓝底标记今天。农历月首表从与交互稿相同的 ICU Chinese Calendar 生成，支持浏览 2000–2099 年；春节、元宵、端午、七夕、中秋、重阳、腊八、除夕、元旦、劳动节和国庆按日期计算，闰月不重复农历节日。测试包含香港天文台历表的春节、2023 闰二月、2025 闰六月和 2033 闰冬月样例。
- **时钟**：PCF8563（I²C 地址 `0x51`，SDA19/SCL20）保存 UTC，启动时检查低电压标志，手机配网时初始化。使用 64 位时间计算，避免 2038 年溢出。日历模式按配置的本地时区在每天 00:00 定时唤醒，更新日期、农历和今天标记，全刷完成后继续深睡，不主动开启 Wi-Fi；跨月、跨年时，正在显示的当前月自动跟到新的月份，手动翻看的其他月份保留。图片模式只用按键唤醒。设备需持续供电且 RTC 时间有效。当前使用固定 UTC 偏移，不自动跟随夏令时，也未启用 NTP；需要校时时可从在线「系统设置」页同步手机时间和设置时区。若 RTC 写入失败，手机会提示，断电后需重新校时。
- **上传**：每像素 4 位，高半字节为前一个像素；索引依次为白、黑、红、黄、绿、蓝，固定 192,000 字节。浏览器优先发送更小的 zlib/DEFLATE 数据，不支持压缩则发送原位图。设备限制输入和解码上限，检查完整压缩流、长度、颜色索引及 CRC32。随机 128 位上传码通过 URL fragment 传递，接口验证 Bearer 凭据；重复提交同一请求号不会重复入册。局域网接口使用 HTTP。
- **相册**：8 MB Flash 中划出 3 MiB LittleFS，保存最近 8 张和写入临时文件。先写临时文件、读回校验、原子改名提交，再淘汰最旧照片；重启扫描有效文件并删除未完成写入。配置和显示状态保存在单独的 NVS 命名空间。挂载失败不自动清除已有数据；空白分区可自动初始化，其他情况由设备设置中的恢复出厂明确初始化。
- **并发与省电**：按键采样、HTTP 服务和电子纸刷新分别运行，刷新队列只保留最后一页。显示内容指纹相同时跳过全刷，休眠前保存模式和页码。配网页只接受设备热点接口的请求，家庭网络不能访问配网接口。

硬件和日期依据：[Seeed 按键与外设](https://wiki.seeedstudio.com/reterminal_e10xx_with_arduino_peripherals/)、[Seeed RTC 与深睡](https://wiki.seeedstudio.com/reterminal_e10xx_with_arduino_peripherals_2/)、[香港天文台历表](https://www.hko.gov.hk/tc/gts/time/conversion.htm)。

## 构建和自动验证

从仓库根目录运行，无需 `config.h`、服务端或上传网页文件系统：

```sh
pio run -d ink-screen/e1002-standalone/firmware
python3 ink-screen/e1002-standalone/firmware/tools/check.py
```

主机测试需要 C++17 编译器、Python3 和 Node.js（支持 CompressionStream）。覆盖 2000–2099 全日期公历往返、月历布局、农历连续性与历表样例、长短按和组合键、时钟回绕、位图/CRC、相册淘汰/重试/写入故障/重启恢复，以及手机取景、六色打包、DEFLATE 往返和不压缩回退。

## 实机验收（待执行）

- Android 和 iPhone 各完成一次扫码配网，验证错误密码重试、手动入口、Wi-Fi 失效提示、双键设置和取消恢复出厂。
- 检查跨年、闰年二月、六行月份、农历初一、闰月和春节；断网跨日应更新今天，彻底断电后 RTC 应保持时间。
- 两种模式均可长按开启上传。第 4 分钟打开页面后再获得 5 分钟；只轮询状态不会续时；到期关闭服务并保留画面。验证 DHCP 地址变化和未变化两种情况；服务开启时右上角出现绿色灯，关闭后完成一次全刷并显示空心圆点，再进入深睡。
- 上传横图、竖图、透明 PNG，检查取景和二维码遮挡区一致。验证压缩和原位图两种传输，拒绝错误长度、颜色、CRC、压缩流与上传码。
- 上传第 9 张后离线浏览最新 8 张。分别在传输、写临时文件、提交、淘汰阶段断电，确认已提交旧照片可恢复。
- 全刷期间连续翻页、上传、双键长按，确认最终画面和手机「刷新完成」状态一致。
- 验证三键唤醒、实体屏二维码可扫性，测量上传、全刷和深睡耗电。编译和主机测试不能替代以上硬件验证。
