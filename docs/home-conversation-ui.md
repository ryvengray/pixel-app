# 首页输入与等待反馈

首页保留最新一组用户发言和助理回复。用户消息右对齐，以较小文字、轻渐变与右侧细标记呈现；Greta 回复使用更舒展的文字与不对称柔和底形，不使用三角尾巴。双方有简短署名，长消息可点击展开，小屏对话区限制高度并允许滚动。首页移除右上方“动态 · 查看”，对话区起点从顶部 118dp 提前到 84dp，利用原入口的留白呈现对话内容；工具结果与操作记录可从“功能与设置 → 提醒与最近结果”查看完整详情，底部只放输入。

消息区与宠物舞台上下分开：上方独立滚动，下方宠物居中，左右保留 `home_pet_left_slot` / `home_pet_right_slot` 两个空展示区。舞台与消息、输入之间保留间隔；键盘动画期间按可用高度重新分配两区，宠物画面与点击区域同步移动和缩放。背景保持全屏。极小可用高度时暂停展示宠物，保证输入可用；其他页面的宠物使用原有定位。

文字输入使用独立的编辑状态：点击“轻点输入…”后立即隐藏语音/闲置提示，键盘出现前收到的隐藏回调不会撤销编辑。只有键盘实际从显示变为隐藏、且没有草稿时，才收起空输入框。已有草稿在关闭键盘后保留；空白消息禁用发送。发送后收起键盘，文字进入上方消息区。IME 动画期间只移动输入栏，动画结束再确认键盘状态，避免中间帧反复切换编辑/语音布局。

输入栏改为透明横线样式：闲置时显示“轻点输入…”和“按住说话”，保留 60dp 点击高度；编辑时使用 60dp 最小高度、16sp 文字和 44dp 箭头发送按钮，最多展开两行，长草稿在内部滚动。下方细线随输入字符数平滑点亮，发送后复位；它是书写反馈，不代表字数上限。浅色/深色使用各自的线条颜色，底部轻微渐变衬底保证照片上的文字可读性。开启“减少动态效果”后横线直接更新，不播放过渡。

输入区和横线左右铺满页面，去掉底部 10dp 外边距，横线区域收至 2dp，贴住屏幕安全区域下沿或键盘上沿。闲置入口使用 16sp / 15sp 字号和轻微字距；文字与按钮保留内边距；底部渐变衬底也横向延展，不形成独立方框。Activity 在分发按下事件时判断是否点在编辑行外，收起键盘并清除焦点，草稿仍保留；事件继续交给原目标，所以宠物和其他入口的点击正常生效。编辑文字与发送按钮位于同一受保护区域，点按它们不会提前收起键盘。

发送合并等待和 Agent 网络请求期间，宠物进入轻微摆动、抬眼及头顶圆点的思考状态，原有旧回复暂时隐藏，文字状态显示“Greta 正在想…”。回复成功、失败或首页暂停时停止等待反馈；失败保留重试入口。开启“减少动态效果”后不播放循环动效，仍保留静态状态提示。

“功能与设置 → 外观 → 字体”提供“清晰”和“书卷”两种风格，附同文案预览。清晰保留设备默认字形与各处字重，书卷使用系统 serif 字族并保留字重和斜体；中文具体字形取决于设备内置字体。选择保存到本机，立即更新首页与设置面板，其他页面在打开、恢复或添加新内容时应用；切换不重建页面，不清空输入草稿。首页详情弹窗与语音层同样使用所选字体。

语音页采用简约科技风，跟随首页深浅主题：深色为墨蓝底与冰青强调，浅色为雾白底与深青强调；顶部仅保留小号标题及状态，27sp实时文字直接呈现在留白区域，无卡片边框。下方为144 × 34dp细线声波；长转写自动滚动到末尾，减少动态效果时不播放循环声波。

语音界面以右下角语音入口实际按下的屏幕位置为圆心，“取消录音”和“编辑文字”以相同半径（常规152dp）分布在左上方扇形圆弧的两个位置。手指靠近时，图标、文字、渐变底色、径向光晕和弧线随距离逐渐染色；进入目标后柔和点亮并轻震，滑离时平滑淡出。视觉用约65ms时间常数追随距离，帧间连续过渡，不重启动画；减少动态效果时直接按距离呈现色阶。目标周围增加随渐变显现的范围环；滑动时显示起点到手指的连线，并在指尖上方28dp显示亮点，避免被手指遮住。上方独立提示条始终显示当前松手动作：未选中时明确“松开将发送”，靠近目标时提示继续滑动；选中后显示“松开将取消／松开后编辑”、结果说明及目标勾选标记，并给予确认震动。提示与松手执行共用即时目标状态，渐变仅作视觉反馈。目标边缘保留容差以避免抖动；滑回原点恢复松开发送。取消／编辑均在松手后执行。圆心附近“松开发送”使用12sp轻量文字和112 × 44dp点击区域，取消／编辑采用线性矢量图标与短标签，无常驻按钮边框，选中后才出现浅色底和强调色；圆弧只保留细线，原点以细环表示。语音入口及覆盖层按钮关闭应用点击音。按用户选择保留系统语音服务提示音，不临时静音媒体声，不修改音量。

语音启动优先尝试设备端识别；设备端可用并不代表中文模型已安装，启动报错或 12 秒未就绪时会销毁旧会话并回退到系统默认识别，回退不强制离线。服务繁忙、断连或客户端错误最多重连两次；无匹配和静音超时在手指仍按住时继续监听，已有转写会保留。取消、退出或切换识别器后，旧会话回调不再影响新会话。错误提示区分权限、中文模型、网络、麦克风和服务繁忙，诊断日志 `GretaVoice` 仅记录错误码与会话状态，不记录转写内容。长按期间禁止父容器拦截手势，结束后恢复；启动失败后的松手不再叠加短按提示。真实 Pixel 中文转写和长按流程尚未验证，本次只确认开发版编译成功。

主要实现：

- `HomeConversationView.java`：编辑状态、上方消息区、自动增高与请求反馈。
- `MainActivity.java`：IME 动画过程的输入栏位置、字体选项和宠物状态连接。
- `AppTypography.java` / `GretaApplication.java`：保存并应用各页面的字体风格，保留文字大小与强调。
- `ConversationSurface.java` / `ComposerUnderline.java`：两种发言底形与书写进度横线。
- `PetScene.java` / `pet.frag`：平滑思考状态与绘制。
